The approach

How a chapter goes from scary to solved.

01

See it before you solve it

Each topic starts with the picture or the reason behind it. Once you know why a formula works, you stop forgetting it.

tan θ = sin θ / cos θ → why the graph has asymptotes
02

Learn the question types

Cambridge asks the same ideas in a handful of recurring shapes. You learn to recognise each shape and the first line that unlocks it.

"Show that…" · "Hence…" · "Find the range of k…"
03

Assignments, then real papers

Every topic ends with a numbered assignment, then past-paper questions topic by topic, then full timed papers as the exam gets close.

Assignment #13 → 0580/42 · 0606/12 · 9709/52
04

Think like the examiner

Mark schemes and examiner reports show where marks are won and lost. You learn to write the working that collects every method mark.

M1 A1 B1 → method, accuracy, independent
05

Check it the same night

Send your working to the AI paper checker and see which marks you earned, where you lost the rest and the working that gets them back, before the next class.

photo of your page → M1 ✓ A1 ✓ A0 ✗ → fixed

          9709 · Pure 1 styleQuadratics[4 marks]

          Q4 Find the set of values of k for which the line y = kx − 3 does not meet the curve y = x² − 2x + 1.

          1. x² − 2x + 1 = kx − 3M1
          2. x² − (2 + k)x + 4 = 0
          3. b² − 4ac > 0M1
          4. (2 + k)² − 16 > 0
          5. k² + 4k − 12 > 0
          6. (k + 6)(k − 2) > 0
          7. k = −6,  k = 2A1
          8. k < −6 or k > 2A0
          Tap a line with a mark or a red underline to read the examiner's comment.

          x² − (2 + k)x + 4 = 0 No intersection ⇒ b² − 4ac < 0 (2 + k)² − 16 < 0 (k + 6)(k − 2) < 0 −6 < k < 2
